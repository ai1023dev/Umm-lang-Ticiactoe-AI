### 게임 방법
1. https://www.ryugod.com/pages/ide/umm에 접속합니다.
2. 코드 에디터에 main.umm을 복붙합니다.
3. main.umm의 183ln에 case.umm을 복붙합니다.
4. 실행버튼을 누르고 터미널에 유저 선공이라면 0, AI 선공이라면 1을 입력합니다.
5. 좌상단 칸이 1, 우하단 칸이 9로 터미널에 입력하며 게임 하세요
6. 대국 종료는 구현을 안해서 게임이 끝나면 Ctrl+C로 exit하세요
